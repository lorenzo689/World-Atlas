# Map registration and border accuracy

Modern close zoom uses camera-local OpenStreetMap international land boundaries and ocean coastlines from [OpenFreeMap](https://openfreemap.org/quick_start/), using the [OpenMapTiles schema](https://openmaptiles.org/schema/boundary/). Only `admin_level=2` land boundaries are used; maritime boundaries and internal administrative boundaries are not drawn as country borders. Disputed boundaries have a separate amber line. Attribution appears while this layer is visible.

The TileJSON revision is resolved once per viewer. Requests use that immutable revision, preventing mixed dataset versions in one view. Four concurrent downloads, 20/40 wanted tiles on low-end/standard devices, a 32/64 tile LRU cache, transferable worker decoding and three merged GPU line batches bound work. Decoded tiles have a 600,000-float ceiling; merged GPU positions have a 2,000,000-float (8 MB) ceiling. Oversized geometry retains the local fallback. Requests time out and leaving the viewport cancels downloads. Historical scenarios do not request modern OSM tiles. Until the entire visible footprint is available, packaged Natural Earth lines remain visible; polar regions and offline operation also retain this fallback. Nothing is uploaded to the tile provider; tile coordinates reveal the viewed region.

Natural Earth **1:10 million** is a cartographic scale, not ten-metre accuracy. OSM close zoom provides more detail, but neither source guarantees surveyed, legally authoritative borders everywhere. Dataset updates, zoom generalization, disputed sovereignty, imagery age and georeferencing can affect agreement. The satellite texture is a global image mosaic, not a current orthophoto survey. Country selection/fills still use the packaged polygons. Historical CShapes boundaries and schematic occupation areas retain their independently documented precision; current borders must never replace historical geometry. Territorial control is a separate dated source, not a sovereignty boundary.

Labels have stable geographic identities and anchors on the relevant sphere surface. Only label selection/collision work is throttled; projection uses the current camera world matrix on every rendered frame. Imagery patches share the earth radius and use polygon depth offset, avoiding elevated-surface parallax. Border chords are subdivided before spherical projection to avoid cutting through the surface.

Verification: projection and real MVT fixture tests; `npm run smoke:detail` tests offline fallback, idle rotation, per-frame anchor error (maximum 1 pixel), stable DOM identities and 65 draw-call ceiling; `npm run smoke:detail -- --osm-fixture` exercises the streamed layer with pinned decoder input under production CSP. `--live-osm` additionally verifies the current external source and is intentionally not a network-dependent CI gate. The fixture browser run repeats one tile payload to test the loading/rendering pipeline; geographic projection accuracy is checked separately against the fixture's actual tile coordinates in unit tests.
